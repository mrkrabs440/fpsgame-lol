# 🎮 병맛 3D FPS — ONLINE FPS (완전체)

> 반동 없는 에임 고정 슈터 + 월간 시즌제 + **라운드마다 무기 2개(원거리1+근접1)만**

브라우저에서 도는 멀티플레이 3D FPS. Three.js + Express + Socket.io.
회원가입 → 방 생성 → 6가지 게임모드. 봇이 알아서 채워줘서 혼자 놀아도 됨.

---

## 🚀 실행

```bash
npm install
npm start
# → http://localhost:3000
```

Windows 는 그냥 **`실행.bat`** 더블클릭 (Node 설치 확인 + 의존성 자동 설치 포함).

### 포트
| 프로젝트 | 포트 |
|---|---|
| **이 게임 (FPS)** | **3000** |
| openworld (술래잡기) | 3001 |
| brainrot (타이쿤) | 3002 |

### 배포 (Render)
`render.yaml` 포함. `DATABASE_URL` 환경변수 넣으면 Postgres, 없으면 `data/*.json` 파일 저장.

## 🛝 슬라이드 (CS2 스타일)

```
Shift(달리기) → W(앞) 로 달린 상태에서 C
```

- 달리기 속도 6.5 이상일 때만 발동
- 진입 즉시 몸 낮춤 + **속도 부스트 (9 → 12 m/s)**
- 관성 감속 (초당 7, 최저 2.6) · 최대 1.15초 · 진행방향 고정 + 약한 조향
- **사격해도 유지됨**
- 종료: `C` 해제 / 속도 소진 / 시간 만료 / **점프** / 감전 / 사망
- 발동 불가: 점프 중 · 감전 상태 · 천천히 걷는 중
- **상대 화면에서도 보임** — 몸 숙이고 다리 뻗는 슬라이드 자세로 재생

## ☢ 핵 (관리자 전용, N 키)

| 항목 | 내용 |
|---|---|
| 권한 | 가입 ID `Tlqkfsusemfdk69` (서버 판정, 클라 조작 불가) |
| 작동 | `N` 키로 가동 (20초) / 다시 누르면 해제 |
| 발사 | **조준점에 적이 있으면 자동으로 발사** (연사 0.12초) |
| 피해 | 999 = 한방 처형 (서버 상한 160 → 100HP 즉시 사망) |
| 쿨다운 | 15초 |

**은밀 설계** — 남들 눈에는 평범한 사격으로 보임
- 총구에서 출발 (자기 총 위치) → 상대는 "그냥 한 발 맞은 것"으로 판단
- `player:shoot` 중계 발송 → 상대 화면에서도 관리자 총에서 섬광이 나감
- 킬피드 무기명은 **현재 장착한 무기 그대로** (M4로 쏘면 [M4A1]로 표시)
- 벽 관통 (핵답게) — 단, 트레이서도 그대로 보임
- 관리자 전용 UI(☢ 태그, 조준점 색상 변경)는 **자기 화면에만** 표시
- 아군으로는 발사 안 됨 (팀 체크)

## 📁 구조

```
gun game/
├── server.js          # Express + Socket.io 서버 (권한·안티치트·시즌·로드아웃)
├── 실행.bat            # 안전한 실행 (작업스케줄러 미사용)
├── 작업스케줄러_점검.bat # schtasks.exe 대신 PowerShell API로 점검
├── render.yaml        # Render 배포 설정
├── data/              # users / sessions / rooms / cheats (JSON 또는 Postgres)
└── public/
    ├── index.html     # 로비 · HUD · 무기선택 · 개발자통계
    ├── admin.html     # 🛡 관리자 콘솔 (치트 통계)
    ├── css/style.css
    └── js/
        ├── app.js     # 로그인 · 방 · 랭킹 · 개발자통계
        └── game.js    # Three.js 3D 엔진 + 무기 15종 + 애니메이션
```

## 🛡 보안 메모

- 이 게임은 `schtasks.exe` / 작업 스케줄러를 **전혀 사용하지 않습니다**
- 레지스트리 변경 · 관리자 권한 필요 없음
