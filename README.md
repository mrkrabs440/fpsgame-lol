# 🎮 병맛 3D FPS — ONLINE FPS (완전체)

> 반동 없는 에임 고정 슈터 + 월간 시즌제 + **갈색 조랑말이 총인 미친말총**

브라우저에서 도는 멀티플레이 3D FPS. Three.js + Express + Socket.io.
회원가입 → 방 생성 → 6가지 게임모드. 봇이 알아서 채워줘서 혼자 놀아도 됨.

---

## 🚀 실행

```bash
npm install
npm start
# → http://localhost:3000
```

Windows 는 그냥 **`실행.bat`** 더블클릭 (Node 설치 확인 + 의존성 자동 설치 포함).

### 포트
| 프로젝트 | 포트 |
|---|---|
| **이 게임 (FPS)** | **3000** |
| openworld (술래잡기) | 3001 |
| brainrot (타이쿤) | 3002 |

### 배포 (Render)
`render.yaml` 포함. `DATABASE_URL` 환경변수 넣으면 Postgres, 없으면 `data/*.json` 파일 저장.

| 방어 | 내용 |
|---|---|
| 슬롯 강등 | 클라가 `wi:10/11` 조작해도 서버가 권한 없으면 9번으로 대체 |
| 데미지 | 클라가 1을 보내도 서버가 999로 덮어씀 |
| 패킷 무시 | 권한 없는 유저의 `op:true` / `mad:true` / `mad:blast` 전부 무효 |
| 닉네임 탈취 | 남이 전용 닉네임으로 변경 시도 → **403** |
| 권한 회수 | 닉네임 변경 시 즉시 권한 박탈 + 총 자동 회수 |

> 전용 닉네임은 **본인만 사용 가능** — 남이 바꿔치기 불가.

## 🛝 슬라이드 (CS2 스타일)

```
Shift(달리기) → W(앞) 로 달린 상태에서 C
```

- 달리기 속도 6.5 이상일 때만 발동
- 진입 즉시 몸 낮춤 + **속도 부스트 (9 → 12 m/s)**
- 관성 감속 (초당 7, 최저 2.6) · 최대 1.15초 · 진행방향 고정 + 약한 조향
- **사격해도 유지됨** (CS2는 끊기지만 여기는 안 끊김)
- 종료: `C` 해제 / 속도 소진 / 시간 만료 / **점프** / 감전 / 사망
- 발동 불가: 점프 중 · 감전 상태 · 천천히 걷는 중
- **상대 화면에서도 보임** — 몸 숙이고 다리 뻗는 슬라이드 자세로 재생

## 📁 구조

```
gun game/
├── server.js          # Express + Socket.io 서버 (권한·안티치트·시즌)
├── 실행.bat            # 안전한 실행 (작업스케줄러 미사용)
├── 작업스케줄러_점검.bat # schtasks.exe 대신 PowerShell API로 점검
├── render.yaml        # Render 배포 설정
├── data/              # users / sessions / rooms / cheats (JSON 또는 Postgres)
└── public/
    ├── index.html     # 로비 · HUD · 상점
    ├── admin.html     # 🛡 관리자 콘솔 (치트 통계)
    ├── css/style.css
    └── js/
        ├── app.js     # 로그인 · 방 · 랭킹
        └── game.js    # Three.js 3D 엔진 + 무기 + 애니메이션
```
